# 8 Модулей Чернильных Фонов

## Обзор

Создано 8 различных модулей чернильных жидкостных фонов с правильной интерактивностью и разными эффектами. Все фоны реагируют на движение мыши и используют цветовую палитру сайта.

## 🎨 Модули

### 1. **Thick Ink** (`InkFluid1`)
- **Эффект**: Густая вязкая чернильная жидкость
- **Скорость**: Медленное тяжелое течение
- **Интерактивность**: Сильное влияние мыши на поток
- **Цвет**: Преимущественно черный с серыми оттенками

### 2. **Droplets** (`InkFluid2`)
- **Эффект**: Капающая и растекающаяся чернила
- **Скорость**: Средняя с капельными переходами
- **Интерактивность**: Создает новые капли вокруг курсора
- **Цвет**: Мокрая бумага с чернильными пятнами

### 3. **Waves** (`InkFluid3`)
- **Эффект**: Волновая поверхность как на воде
- **Скорость**: Плавные волны с круговыми рябями
- **Интерактивность**: Круговые волны от мыши
- **Цвет**: Темный океан с пеной на гребнях

### 4. **Swirls** (`InkFluid4`)
- **Эффект**: Завихрения и вихри чернилы
- **Скорость**: Динамичные вращательные движения
- **Интерактивность**: Множественные вихри вокруг мыши
- **Цвет**: Мистический с энергичными вспышками

### 5. **Mist** (`InkFluid5`)
- **Эффект**: Туманная дымная чернила
- **Скорость**: Очень медленное движение тумана
- **Интерактивность**: Туманное облако вокруг курсора
- **Цвет**: Мягкий туман с мерцанием

### 6. **Streams** (`InkFluid6`)
- **Эффект**: Потоки и струи чернилы
- **Скорость**: Направленные потоки
- **Интерактивность**: Создает потоки от мыши
- **Цвет**: Активные потоки с брызгами

### 7. **Crystals** (`InkFluid7`)
- **Эффект**: Кристаллизующаяся чернила
- **Скорость**: Медленный рост кристаллов
- **Интерактивность**: Ускоряет кристаллизацию вокруг мыши
- **Цвет**: Кристаллические структуры с преломлением

### 8. **Deep Ocean** (`InkFluid8`)
- **Эффект**: Глубокий океан чернилы
- **Скорость**: Многослойные волны разной глубины
- **Интерактивность**: Поверхностные ряби от мыши
- **Цвет**: Очень темный морской фон

## 🚀 Доступ

- **Главная страница**: `http://localhost:3001` - использует Thick Ink
- **Витрина фонов**: `http://localhost:3001/backgrounds` - все 8 модулей

## 🔧 Технические особенности

### Общие для всех:
- **Интерактивность**: Реакция на глобальное движение мыши
- **Производительность**: Оптимизированные шейдеры (64x64 геометрия)
- **Цвета**: Соответствие палитре сайта
- **SSR**: Правильная обработка серверного рендеринга

### Исправления:
- ✅ Реакция на движение мыши через `state.pointer`
- ✅ Правильное позиционирование (`z: -0.5`)
- ✅ Медленная скорость для вязкости
- ✅ Правильная нормализация координат

### Шейдерные эффекты:
- Simplex noise для органических движений
- FBM для многослойности
- Экспоненциальные функции для плавных переходов
- Тригонометрические функции для волн

## 💡 Использование

```tsx
// Импорт нужного модуля
import InkFluid1 from '@/components/backgrounds/InkFluid1';

// В Canvas компоненте
<Canvas>
  <InkFluid1 />
</Canvas>
```
