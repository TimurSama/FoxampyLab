# Галерея с Каруселью - Обновление главной страницы

## 🎯 Что изменилось

### ❌ Удалено:
- **2 кейса проектов** (Web3 Bank и Mail Services)
- **Текстовое описание галереи** с большим блоком информации
- **Статичные карточки** с технологиями

### ✅ Добавлено:
- **Интерактивная карусель** с 8 элементами
- **Разные типы контента**: проекты, фото, дизайн, видео
- **Автопоказ** с возможностью управления
- **Адаптивный дизайн** для всех устройств

## 🎨 Компоненты карусели

### Основной слайд:
- Большой экран с описанием текущего элемента
- Градиентные фоны для каждого типа контента
- Иконки категорий (Code, Camera, Palette, Video)
- Кнопки навигации при ховере

### Миниатюры:
- Сетка 8 превью (4 на мобильных, 8 на десктопе)
- Цветовая кодировка по типам
- Индикатор текущего слайда
- Быстрый переход к любому элементу

### Управление:
- **Автопоказ**: включается/выключается
- **Ручное управление**: кнопки вперед/назад
- **Прямой переход**: клик по миниатюре
- **Индикаторы**: точки для текущей позиции
