# Интерактивный Жидкостной Фон

## Описание

Создан красивый тягучий жидкостной фон с эффектом нефти/ртути в цветовой палитре сайта. Фон имеет интерактивную реакцию на движение мыши и автоматически адаптируется под устройство.

## Компоненты

### 1. `InteractiveOilBackground.tsx`
Основной WebGL компонент с шейдерами для создания реалистичной жидкостной анимации:
- **Эффекты**: Вязкие волны как нефть/ртуть
- **Интерактивность**: Реакция на движение мыши
- **Производительность**: Оптимизированные шейдеры
- **Цвета**: Соответствует палитре сайта (черный, серый, белый)

### 2. `OilCSSBackground.tsx`
CSS fallback для устройств без поддержки WebGL:
- **Анимации**: Многослойные градиенты
- **Интерактивность**: Отслеживание мыши
- **Совместимость**: Работает везде
- **Производительность**: Легковесный

### 3. `SmartOilBackground.tsx`
Умный компонент-обертка:
- **Автовыбор**: WebGL на десктопе, CSS на мобильных
- **Детекция**: Проверка поддержки WebGL
- **Fallback**: Плавная деградация

### 4. `InteractiveOilBackgroundWrapper.tsx`
Canvas обертка для WebGL версии с правильными настройками.

## Использование

### Внедрение в страницу:

```tsx
// Динамический импорт с отключенной SSR
const SmartBackground = dynamic(
  () => import('@/components/visuals/SmartOilBackground'),
  { ssr: false }
);

// В компоненте:
<div className="fixed inset-0 z-0">
  <SmartBackground />
</div>
```

### Демо страница:
Откройте `/demo/background` для тестирования всех вариантов.

## Технические особенности

### WebGL версия:
- **Шейдеры**: Custom GLSL с улучшенным noise
- **Производительность**: 128x128 геометрия, адаптивный DPR
- **Интерактивность**: Реальное время реакции на мышь
- **Эффекты**: Металлические блики, вязкость, поверхностное натяжение

### CSS версия:
- **Анимации**: Multiple keyframes для волнообразных движений
- **Интерактивность**: CSS transforms с реакцией на мышь
- **Производительность**: GPU ускоренные transform
- **Эффекты**: Градиенты, blur, mix-blend-mode

## Цветовая палитра

Соответствует основным цветам сайта:
- `#030303` - Густая нефтяная основа
- `#0a0a0a` - Темные переливы  
- `#252530` - Светлые волны
- `#d5d7dc` - Ртутные блики

## Оптимизации

- **Адаптивность**: Автоматический выбор технологии
- **Производительность**: Оптимизированные рендеринг
- **Совместимость**: Работает на всех устройствах
- **SSR**: Правильная обработка серверного рендеринга
