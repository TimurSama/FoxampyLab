# 🏗️ Архитектура Telegram бота и обработки заказов

## 📊 Как это работает

### Два способа получения заявок:

#### 1. **С сайта (GitHub Pages)**
- Пользователь заполняет форму на сайте
- Форма отправляет заявку через Telegram Bot API **напрямую вам в Telegram**
- Работает без дополнительного сервера (только клиентская часть)

#### 2. **Через Telegram бота**
- Пользователь открывает бота в Telegram
- Бот работает на отдельном сервере (Railway, Heroku, VPS)
- Пользователь выбирает язык, заполняет формы в боте
- Бот отправляет заявку **вам в Telegram**

### Куда приходят заявки?

**ВСЕ заявки приходят вам в Telegram!**

- **Ваш Telegram ID:** `268494758`
- **Формат:** Красиво оформленные сообщения
- **Источник:** Указывается, откуда пришла заявка

## 🚀 Что нужно сделать

### ✅ Уже готово:
1. Код бота создан (`bot/index.js`)
2. Интеграция с сайтом работает (`lib/telegram.ts`)
3. Все формы настроены

### 📋 Что нужно сделать:

#### 1. **Установить зависимости для бота:**
```bash
npm install
```

#### 2. **Протестировать локально:**
```bash
# Создайте .env.local с токенами
npm run bot
```

#### 3. **Задеплоить бота на сервер:**
- **Рекомендуется:** Railway (бесплатно)
- **Альтернативы:** Heroku, VPS

## 🎯 Ответы на вопросы

### ❓ Бот будет работать только с GitHub деплоем?

**Нет!** Бот работает **отдельно** на своем сервере:
- Сайт на GitHub Pages (статический)
- Бот на Railway/Heroku/VPS (серверный)

### ❓ Куда приходят заказы?

**Вам в Telegram!** (ID: 268494758)

Все заявки приходят в виде красивых сообщений:
- 📅 Заявки на консультацию
- 🎯 Заявки на услуги
- ✉️ Контактные сообщения

### ❓ Нужен ли чат с ботом?

**Да!** Для работы бота нужно:
1. Начать чат с ботом (`/start`)
2. Выбрать язык
3. Использовать меню

### ❓ Как настроить автодеплой?

**GitHub Pages:**
- Уже настроен через GitHub Actions
- Секреты добавляются в GitHub Secrets

**Telegram Бот:**
- Деплоится отдельно на Railway/Heroku
- Переменные окружения настраиваются на платформе
