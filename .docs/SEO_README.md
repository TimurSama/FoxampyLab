# SEO Оптимизация Foxampy LAB

## Обзор

Этот документ описывает SEO-стратегию и техническую реализацию для сайта Foxampy LAB.

## Цели

1. **Поисковая оптимизация**: Высокие позиции в Google по целевым запросам
2. **LLM-оптимизация**: Попадание в ответы ChatGPT, Claude, Perplexity и других LLM
3. **Конверсия**: Привлечение качественных B2B-лидов (CTO, основатели стартапов, Tech Lead)

## Целевая аудитория

### Основная ЦА
- CTO, Head of Innovation, Tech Lead
- Основатели стартапов
- Продюсеры digital/media/CGI
- Архитекторы IT-систем и Web3-решений

### Боли ЦА
- Нет целостной архитектуры продукта
- Сложно объединить IT, дизайн и R&D
- Нужны нестандартные инженерные решения
- Нужен партнёр, а не просто исполнитель

## Техническая реализация

### 1. Метаданные

Централизованная система метаданных в `lib/seo/metadata.ts`:

```typescript
import { generateMetadata } from '@/lib/seo/metadata';

export const metadata = generateMetadata('home');
```

Каждая страница имеет:
- Уникальный title с ключевыми словами
- Оптимизированный description (150-160 символов)
- Релевантные keywords
- Open Graph теги
- Twitter Card теги

### 2. Структурированные данные (JSON-LD)

Реализованы схемы:
- **Organization**: Информация о компании
- **WebSite**: Данные о сайте
- **FAQ**: Часто задаваемые вопросы
- **Service**: Описание услуг
- **Breadcrumb**: Навигационные цепочки
- **Article**: Для блога и кейсов
- **JobPosting**: Для вакансий

Использование:

```typescript
import { getOrganizationSchema, getFAQSchema } from '@/lib/seo/structured-data';

const schema = getOrganizationSchema();
```

### 3. FAQ Секции

FAQ компонент с автоматической генерацией структурированных данных:

```typescript
import FAQSection from '@/components/sections/FAQSection';
import { homeFAQ } from '@/lib/seo/faq-data';

<FAQSection items={homeFAQ} />
```

### 4. Sitemap и Robots.txt

- **Sitemap**: Автоматически генерируется в `app/sitemap.ts`
- **Robots.txt**: Настроен для всех поисковых и AI-краулеров

## Оптимизация для LLM

### Что делает контент LLM-friendly:

1. **Чёткая структура**
   - Используйте заголовки H1-H3
   - Разбивайте текст на секции
   - Используйте списки

2. **Определения и объяснения**
   - Объясняйте термины
   - Приводите примеры
   - Отвечайте на вопросы "что", "как", "зачем"

3. **FAQ блоки**
   - На каждой странице
   - Конкретные вопросы и ответы
   - Структурированные данные

4. **Технические детали**
   - Конкретные технологии
   - Процессы и методологии
   - Измеримые результаты

### Robots.txt для AI

```
User-agent: GPTBot
Allow: /

User-agent: ChatGPT-User
Allow: /

User-agent: Claude-Web
Allow: /

User-agent: PerplexityBot
Allow: /
```

## Воронка продаж

### Этап 1: Привлечение (Awareness)
**Каналы**:
- SEO (Google)
- LinkedIn
- Telegram
- Behance

**Контент**:
- Экспертные статьи
- Визуальные кейсы

### Этап 2: Прогрев (Consideration)
**Инструменты**:
- Страницы услуг
- Кейсы
- FAQ
- Блог

**Контент**:
- "Как мы работаем"
- "Какие задачи решаем"

### Этап 3: Конверсия (Conversion)
**Точки входа**:
- Форма "Запросить консультацию"
- Кнопка "Обсудить проект"
- Telegram / Email

**Триггеры**:
- "Бесплатный первичный разбор"

- "Оценка feasibility"

### Этап 4: Продажа (Action)
**Процесс**:
1. Первичный контакт
2. Уточнение задачи
3. Предложение формата:
   - Консалтинг
   - Прототип
