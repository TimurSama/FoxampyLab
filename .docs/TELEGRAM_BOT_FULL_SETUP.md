# 🤖 Полная настройка Telegram бота с меню и формами

## 📋 Архитектура решения

### Как это работает:

1. **Сайт (GitHub Pages)** - статический хостинг
   - Формы на сайте отправляют заявки через Telegram Bot API напрямую администратору
   - Кнопка "Связаться в Telegram" открывает бота

2. **Telegram Бот (отдельный сервер)** - интерактивный интерфейс
   - Работает на отдельном сервере (VPS, Railway, Heroku, etc.)
   - Принимает команды от пользователей
   - Собирает данные через формы
   - Отправляет заявки администратору в личные сообщения

3. **Администратор (Вы)** - получает все заявки
   - Все заявки приходят в ваш Telegram (ID: 268494758)
   - И с сайта, и из бота

## 🌐 Деплой бота на сервер

### Вариант 1: Railway (рекомендуется - бесплатный тариф)

1. **Создайте аккаунт на Railway:**
   - Перейдите на https://railway.app
   - Войдите через GitHub

2. **Создайте новый проект:**
   - Нажмите "New Project"
   - Выберите "Deploy from GitHub repo"
   - Выберите ваш репозиторий

3. **Настройте переменные окружения:**
   - В настройках проекта → Variables
   - Добавьте:
     - `TELEGRAM_BOT_TOKEN` = `8224553051:AAGhMoyvUojdI5Mzli2D7LWlkMr_Xah4Deg`
     - `TELEGRAM_ADMIN_ID` = `268494758`

4. **Настройте команду запуска:**
   - В настройках → Settings → Deploy
   - Start Command: `node bot/index.js`

5. **Деплой:**
   - Railway автоматически задеплоит бота
   - Бот будет работать 24/7

### Вариант 2: Heroku

1. **Установите Heroku CLI:**
   ```bash
   npm install -g heroku
   ```

2. **Создайте Procfile:**
   ```
   worker: node bot/index.js
   ```

3. **Деплой:**
   ```bash
   heroku create foxampy-bot
   heroku config:set TELEGRAM_BOT_TOKEN=8224553051:AAGhMoyvUojdI5Mzli2D7LWlkMr_Xah4Deg
   heroku config:set TELEGRAM_ADMIN_ID=268494758
   git push heroku main
   ```

### Вариант 3: VPS (свой сервер)

1. **Подключитесь к серверу:**
   ```bash
   ssh user@your-server.com
   ```

2. **Установите Node.js:**
   ```bash
   curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
   sudo apt-get install -y nodejs
   ```

3. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/TimurSama/FoxampyLab.git
   cd FoxampyLab
   ```

4. **Установите зависимости:**
   ```bash
   npm install
   ```

5. **Создайте `.env.local`:**
   ```bash
   nano .env.local
   # Вставьте токены
   ```

6. **Установите PM2 для автозапуска:**
   ```bash
   npm install -g pm2
   pm2 start bot/index.js --name foxampy-bot
   pm2 save
   pm2 startup
   ```

## 🐛 Troubleshooting

### Бот не отвечает:

1. ✅ Проверьте, что бот запущен
2. ✅ Проверьте токен в переменных окружения
3. ✅ Проверьте логи на ошибки
4. ✅ Убедитесь, что начали чат с ботом (`/start`)

### Заявки не приходят администратору:

1. ✅ Проверьте правильность `TELEGRAM_ADMIN_ID`
2. ✅ Убедитесь, что вы начали чат с ботом
3. ✅ Проверьте логи бота на ошибки

### Ошибка "Bot token is empty":

1. ✅ Проверьте переменные окружения
2. ✅ Перезапустите бота после изменения `.env.local`

```javascript
const translations = {

  },
  // ...
};
```

В секции `servicesKeyboard` добавьте новые кнопки:

```javascript
[{ text: '🆕 Новая услуга', callback_data: 'service_new' }],
```
