### Troubleshooting:

**Сообщения не приходят:**
1. Проверьте секреты в GitHub
2. Убедитесь, что бот активирован (`/start`)

1. Проверьте `.env.local` локально
2. Проверьте секреты в GitHub для production
3. Перезапустите dev-сервер
