# 🛡️ ANTI-SPAM STRATEGY
## Безопасное продвижение без риска бана

### ⚠️ Почему важно следовать этой стратегии

- **LinkedIn**: Бан за 50+ connection requests/день
- **Telegram**: Бан за спам в чатах (авто-удаление + репорты)
- **Email**: Попадание в спам-листы, блокировка домена
- **HH.ru**: Капча после 20 откликов, блок аккаунта

## 🎯 БЕЗОПАСНЫЕ СТРАТЕГИИ ПО КАНАЛАМ

### 1. Telegram (самый безопасный)

#### Стратегия A: Мягкий вход (рекомендуется)
```
День 1-3: Только чтение, анализ, без сообщений
День 4-7: 1-2 комментария в день (полезные, не рекламные)
День 8-14: 1 пост/неделю с пользой (кейс, инсайт)
День 15+: Мягкие упоминания услуг в контексте
```

#### Стратегия B: Прямой outreach
```
1. Поиск сообщений с хэштегами #ищу #vacancy #job
2. Ответ только на релевантные (AI-фильтр >80%)
3. Персонализированное сообщение (не шаблон)
4. Задержка 5-10 минут между сообщениями
5. Не более 5 сообщений/час
```

**Шаблон безопасного сообщения:**
```
Привет! Увидел ваш пост о поиске PM на Web3 проект.

Мой опыт релевантен:
• Победитель хакатона Everscale
• Запускал Realting.uz (токенизация недвижимости)
• 7+ лет в продуктах

Могу показать портфолио и обсудить, подхожу ли под вашу задачу.
```

### 2. LinkedIn (средний риск)

#### Connection Strategy
```
1. Просмотр профиля (не более 50/день)
2. Через 2-3 дня: connection request
3. Только если mutual connections или общая группа
4. Персонализированное сообщение с запросом
5. Accept rate >30% = нормально, <10% = остановиться
```

**Шаблон connection request:**
```
Привет [Имя]!

Увидел, что вы [роль] в [компания]. Работаю над похожими проектами в Web3/PropTech.

Хотел бы познакомиться и обменяться опытом.

Тимур
```

**После accept (через 1-2 дня):**
```
Спасибо за коннект, [Имя]!

Вижу, что вы работаете над [проект]. Возможно, будет интересно обсудить, как мы решали похожие задачи в [кейс].

Если актуально — готов созвониться на 15 минут.
```

### 3. Email (высокий риск, но эффективный)

#### Правила безопасности:
1. **Warming up**: Начинать с 5-10 писем/день, увеличивать на 5 каждую неделю
2. **Разнообразие**: Менять темы, тексты, время отправки
3. **Quality over quantity**: Лучше 10 качественных, чем 100 спамных
4. **Unsubscribe**: Всегда включать ссылку отписки
5. **SPF/DKIM/DMARC**: Настроить для домена

**Warming schedule:**
```
Неделя 1: 5 писем/день
Неделя 2: 10 писем/день
Неделя 3: 20 писем/день
Неделя 4: 30 писем/день
Максимум: 50 писем/день
```

### 4. Job Sites (hh.ru, etc)

#### Anti-detect стратегия:
```
1. Разные CV под разные вакансии (адаптация)
2. Не более 20 откликов/день
3. Чередование: 5 откликов, перерыв 1 час
4. Уникальные сопроводительные письма (не копипаст)
5. Разное время откликов (не все сразу)
```

## 📈 ИНДИКАТОРЫ ПРОБЛЕМ

### Telegram
- ⚠️ Сообщения не доставляются (только одна галочка)
- ⚠️ Ограничение на отправку сообщений
- ⚠️ Частые капчи
- 🛑 Аккаунт удален из чатов
- 🛑 Полный бан

### LinkedIn
- ⚠️ "You've reached the weekly invitation limit"
- ⚠️ Temporary restriction on search
- ⚠️ ID verification required
- 🛑 Account restricted
- 🛑 Permanent ban

### Email
- ⚠️ Низкая доставляемость (<80%)
- ⚠️ High bounce rate (>5%)
- ⚠️ Spam folder placement
- 🛑 Blacklisting (Spamhaus, etc.)
- 🛑 Domain blocked

**Действия при проблемах:**
1. Немедленно остановить все активности
2. Подождать 24-48 часов
3. Снизить лимиты в 2 раза
4. Увеличить качество персонализации

## 🔄 РЕЗЕРВНАЯ СТРАТЕГИЯ

Если основной аккаунт забанен:

1. **Telegram**: Новый номер, новое устройство/эмулятор
2. **LinkedIn**: Новый email, новый IP, профиль без связей со старым
3. **Email**: Новый домен, новый SMTP, новый IP
4. **HH.ru**: Новый номер телефона, новое CV

Всегда иметь минимум 2 резервных аккаунта.

## 📊 МОНИТОРИНГ ЗДОРОВЬЯ АККАУНТОВ

Ежедневная проверка:
```sql
-- Telegram
SELECT COUNT(*) FROM messages_sent WHERE date = TODAY;
-- Должно быть < 100

-- LinkedIn
SELECT COUNT(*) FROM connections_sent WHERE date = TODAY;
-- Должно быть < 30

-- Email
SELECT COUNT(*) FROM emails_sent WHERE date = TODAY AND bounced = false;
-- bounce rate должен быть < 2%
```

---

**Важно**: Лучше медленный и стабильный рост, чем быстрый бан и потеря аккаунта.
