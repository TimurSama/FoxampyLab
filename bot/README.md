# 🤖 Telegram Bot для Foxampy Lab

Полноценный Telegram бот с меню, формами и выбором языка.

## 🚀 Быстрый старт

### 1. Установите зависимости

```bash
npm install
```

### 2. Настройте переменные окружения

Создайте файл `.env.local` в корне проекта:

```bash
TELEGRAM_BOT_TOKEN=8224553051:AAGhMoyvUojdI5Mzli2D7LWlkMr_Xah4Deg
TELEGRAM_ADMIN_ID=268494758
```

### 3. Запустите бота

```bash
npm run bot
```

Или с автоперезагрузкой (если установлен nodemon):

```bash
npm run bot:dev
```

## 📱 Функционал

- ✅ Выбор языка (русский/английский)
- ✅ Меню с кнопками
- ✅ Форма консультации
- ✅ Форма заказа услуг
- ✅ Контактная форма
- ✅ Автоматическая отправка заявок администратору

## 🐛 Troubleshooting

Если бот не отвечает:
1. Проверьте токен в `.env.local`
2. Убедитесь, что начали чат с ботом (`/start`)
3. Проверьте логи на ошибки
