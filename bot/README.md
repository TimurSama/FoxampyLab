# 🤖 Telegram Bot для Foxampy Lab

Полноценный Telegram бот с меню, формами и выбором языка.

## 🚀 Режимы работы

Бот может работать в двух режимах:

1. **Standalone режим (Polling)** - для локальной разработки и отдельных серверов
2. **Webhook режим** - для Vercel (serverless functions)

## 📦 Установка

1. **Установите зависимости:**
   ```bash
   npm install
   ```

2. **Переменные окружения:**
   Создайте файл `.env.local` в корне проекта:
   ```env
   TELEGRAM_BOT_TOKEN=8224553051:AAGhMoyvUojdI5Mzli2D7LWlkMr_Xah4Deg
   TELEGRAM_ADMIN_ID=268494758
   ```

## 🔧 Запуск

### Standalone режим (Polling)

Для локальной разработки или отдельного сервера:

```bash
npm run bot
```

Или с автоперезагрузкой:
```bash
npm run bot:dev
```

Для production с PM2:
```bash
pm2 start bot/index.ts --name foxampy-bot --interpreter tsx
```

### Webhook режим (Vercel)

Для работы на Vercel используйте webhook режим. Подробная инструкция в [VERCEL_BOT_SETUP.md](../.docs/VERCEL_BOT_SETUP.md).

После деплоя на Vercel настройте webhook:
```bash
npm run setup-webhook
```

## 🎯 Функциональность

- **Выбор языка**: Пользователи могут выбрать русский или английский
- **Главное меню**:
  - 📅 Записаться на консультацию
  - 🎯 Заказать услуги
  - ✉️ Связаться с нами
  - ℹ️ О нас
  - 🌐 Открыть сайт
- **Формы**: Пошаговые формы для консультаций, заявок на услуги и контактных сообщений
- **Уведомления администратора**: Все отправленные формы приходят администратору (ID: 268494758)

## ⚠️ Важные замечания

- **Начало чата**: Администратор *должен* начать чат с ботом (отправить `/start`), чтобы бот мог отправлять уведомления
- **Хранение данных**: В текущей реализации используется `Map` в памяти. При каждом перезапуске данные теряются. Для production рекомендуется использовать базу данных
- **Деплой**: 
  - Для Vercel: используйте webhook режим (см. [VERCEL_BOT_SETUP.md](../.docs/VERCEL_BOT_SETUP.md))
  - Для других серверов: используйте standalone режим с polling

## 🐛 Устранение неполадок

Если бот не отвечает:
1. Проверьте токен в `.env.local`
2. Убедитесь, что начали чат с ботом (`/start`)
3. Проверьте логи на ошибки
4. Для webhook режима проверьте, что webhook правильно настроен
